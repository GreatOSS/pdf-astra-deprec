# FolioVale changelog

## 0.1.0 preview — 2026-09-27

First implementation, published at https://greatoss.github.io/pdf/ from the GreatOSS/pdf repository.

- Local-first PDF viewer with selectable text, page navigation and zoom.
- Add text, highlights and images; rotate, reorder and delete pages.
- Undo/redo, last-session recovery, close/forget and explicit export feedback.
- PDF export preserving source bytes and tested with independent text readback.
- Responsive desktop/mobile UI, touch placement and keyboard shortcuts.
- Automated model/export and browser checks, plus recorded hands-on testing.

This is a preview, not a claim of complete PDF compatibility. See README.md for current limitations and docs/TESTING.md for tested workflows and remaining coverage.
